# ⚽ Soccer Analytics – Analysis Branch

This branch contains the operational files used for the step-by-step data analysis.

## 📁 Contents

- **players_dataset.csv**
  The raw dataset with player statistics (goals, assists, minutes played, ratings, market value, etc.).

- **soccer_analysis.ipynb**
  A Jupyter Notebook where the entire analysis is performed step by step, including:
  - Data cleaning
  - Feature engineering
  - Creation of performance metrics (goals per match, goals per 90, goal contribution)
  - Data visualization using Matplotlib and Seaborn

## 🛠 Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

This branch is dedicated to experimentation, exploratory data analysis (EDA), and metric development.
