# ⚽ Soccer Player Performance Analysis

This repository contains a data analysis project focused on **soccer player performance**. Using real-world player statistics, the project explores goals, assists, minutes played, ratings, and more to evaluate efficiency and contribution on the field.

---

## 📂 Repository Structure

- **`main` branch**: Contains the cleaned dataset, scripts, and final results.  
- **`operational` branch**: Active workspace with Jupyter Notebooks for experimentation, visualizations, and step-by-step analyses.

---

## 🧰 Technologies Used

This project is built entirely in Python using the following libraries:

- **Pandas** – data manipulation, handling missing values, aggregation  
- **NumPy** – numerical operations and calculations  
- **Matplotlib** – plotting basic charts and custom visualizations  
- **Seaborn** – advanced statistical visualizations, heatmaps, and distribution plots  

---

## 📊 Key Features

- Exploratory Data Analysis (EDA) on numerical and categorical features  
- Calculation of derived metrics:
  - `goals_per_match` – average goals per match  
  - `goals_per_90` – normalized goals per 90 minutes  
  - `minutes_per_goal` – average minutes needed for a goal  
  - `goal_contribution` – total goals + assists per player  
- Visualizations:
  - Top players by goals and goal contributions  
  - Position-wise contribution analysis  
  - Histograms and KDE plots of key metrics  
- Grouping and aggregation by player, position, or league
